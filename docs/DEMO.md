# 3-minute demo

1. **Problem (20 s).** Incomplete applications cause back-and-forth with City staff and delays, and applicants don't know which requirements apply to them.
2. **Preview (30 s).** Click Start, type "backyard porch" and press Enter (it finds "Deck or porch"). On Preview, enter a height of 0.4 m with no roof: **"A permit may not be required"**, and the flow stops there. Change the height to 0.9 m: a permit is likely required, so continue.
3. **One PDF per page (60 s).** Home → load the *Residential deck* sample. Each document has its own page: the application form, site plan, deck plan and side view. Uploading a page's PDF ticks its items (placeholder for now). Remove a file and click Next: it asks before continuing past an unfinished page.
4. **Declaration (15 s).** The required declaration from Section I of the Ontario form. The signature itself belongs on the PDF form.
5. **Summary and confirmation (30 s).** Load the *Commercial interior alteration* sample and walk to the summary: **Application incomplete**, listing the three documents not uploaded (code matrix, key plan, electrical plan). Click one to jump straight to that page. Download the PDF summary. The confirmation page says "Application incomplete". With every document uploaded (for example the *Residential deck* sample), it says **Application appears complete**.
6. **Wrong files (15 s).** On the *Detached garage* sample, upload `fixtures/files/FILE-002/ProtectedPlan.pdf` on the floor plan page ("Upload an unsecured version of the PDF.") and `FILE-006/GaragePlan.pdf` on the site plan page (address mismatch, with both addresses shown).
7. **Close (10 s).** This is preliminary guidance only: it supports City review and never replaces it.
